# HindSight 0.5.13 RC 1

macOS 14+ on Apple Silicon is the official binary target. Intel support remains experimental.

## Changes

- Flow and evidence graphs open at 80% zoom. Both use fixed-size 190×120 minimaps that fit the complete graph surface, preserve aspect ratio, and scale node bounds and viewport indicators to the graph.
- The Reconstruction menu offers `.c`, `.m`, `.h` and `.n` dumps for a discovered binary, current code section, or function at an address, plus existing-batch export and resumable batches. Dump All writes all four formats into `c/`, `h/`, `m/` and `n/` in one destination.
- Reconstruction checkpoints and dumps preserve source identity, exact output hashes, requested format, outcome counts and declaration language requirements. Dumps prefer qualified source, then available machine-state C or explicitly review-only C-like code. Generic unresolved-function review interfaces are not original headers or ABI declarations.
- Objective-C headers retain validated class/member/method declarations and known superclass/protocol names, including supported legacy dyld superclass binds. Supported scalar IMPs can emit Objective-C method adapters over their recovered C bodies; the category packaging is explicitly synthetic. Unknown dependencies and unsupported implementations remain unresolved.
- Public SDK declaration lookup supports source-bound worker analysis and recorded public import providers. Automatic app SDK discovery and runtime provider qualification remain open.
- Expanded scalar/Boolean/void/call and SDK integer pointee reconstruction, with declaration-only FP, stack-argument and supported Apple SDK aggregate headers.
- Fixed oversized prototype-conflict reports and unsafe flattening of unsupported array declarators. Analysis engine: `arm64-analysis-v103-schema129`; reconstruction pass: `arm64-reconstruction-62`.

## Validation and limitations

Fresh credential-free macOS candidate qualification passed on 2026-10-23, including Release build, nested ad-hoc signature verification and embedded worker self-test. Focused gates also passed: 92 void/call configurations with 4,176 native comparisons, 648 SDK-pointee configurations with 59,400 comparisons, and 40 header configurations with 152 successful syntax checks and eight expected language rejections. The candidate report is `build/release-reports/20261023-004553-candidate/`; its source working tree was not yet committed. The separately executed focused matrices are now included in the macOS gate for future runs. Geometry contracts cover minimap projection and the 80% viewport; direct manual graph/UI qualification remains open.

This is a research prerelease, not completion of the reconstruction roadmap. General C++/Swift reconstruction, arbitrary typedefs/aggregates, broad equivalence and app/service crash-restart recovery remain open.

Developer ID signing, notarization and credentialed release validation are intentionally skipped until further notice. The app is ad-hoc signed, not notarized; Gatekeeper may block a downloaded copy. Checksums establish file identity, not publisher trust or absence of vulnerabilities. No Intel release binary is supplied.

The app/worker protocol's `stable` channel string is retained for compatibility; it does not override this GitHub prerelease designation or the validation limitations above. The source package is taken from the release commit. Candidate qualification ran on the source working tree before it was sealed into that commit.
