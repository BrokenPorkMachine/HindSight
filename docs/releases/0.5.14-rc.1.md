# HindSight 0.5.14 RC 1

macOS 14+ on Apple Silicon is the official binary target. Intel remains experimental.

## Fixes

- Include the Darwin SDK declaration catalog in the app target, fixing the Swift build failure after reconstruction catalog support was added.
- Use Darwin `stat` timespec fields for retained catalog integrity checks, and report oversized project type exports through the app's existing error type.
- Accept versioned Apple SDK directories such as `MacOSX27.0.sdk` when validating source-bound declarations.
- Keep only eligible import candidates in worker prototype input so automatic SDK reconstruction batches can resume successfully.
- Align app, Coordinator, worker, VectorEmu, checks, and bundle metadata on 0.5.14 (build 5914).

## Validation and distribution

The arm64 Release app built with Xcode 27.1 on macOS, and its app and nested service signatures verified. The embedded worker health check and VectorEmu version check passed. Source validation passed 242 Python tests (six skipped), plus Swift and source topology checks. HindSight and its Coordinator started from the project build folder.

The app is ad-hoc signed and has not been Developer ID signed or notarized. Gatekeeper may block a downloaded copy. The manual real-target and 8 GiB pressure qualification matrix was not run. This GitHub release is a prerelease; the internal `stable` protocol channel remains for compatibility.
