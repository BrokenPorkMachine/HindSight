# HindSight 0.5.15 RC 1

macOS 14+ on Apple Silicon is the official binary target. Intel remains experimental.

## Changes

- More readable C/Objective-C calls and tail calls: typed scalar constants, stack arguments, paired stores, aggregate return registers, and hidden result buffers.
- Expanded C++ symbol demangling, including member qualifiers, constructors, destructors, and supported operators.
- Stronger Objective-C dispatch evidence and SDK-backed declaration reconstruction, with explicit uncertainty where types or targets remain unresolved.
- Complete function pseudocode takes priority over instruction previews within the report budget.
- Staged binary patch batches validate original bytes, reject overlaps, and save output atomically.
- Version 0.5.15, build 5915; reconstruction engine `arm64-analysis-v125-schema130`, pass 84.

General complete source recovery is still in development. This release does not claim arbitrary Mach-O binaries can be recreated as equivalent original source.

## Distribution

This is an ad-hoc-signed GitHub prerelease, without Developer ID signing or notarization. Gatekeeper may block downloaded copies. Manual real-target and 8 GiB pressure qualification remains deferred. See the attached validation record for executed checks.
