# 0.5.13 RC 1 validation record

Date: 2026-10-23. Official binary: macOS 14+, Apple Silicon only. Intel remains
experimental and is not included in the release ZIP.

The credential-free candidate gate passed:

```sh
env -u VECTORGLASS_SIGN_IDENTITY -u VECTORGLASS_DEVELOPMENT_TEAM -u VECTORGLASS_NOTARIZE_PROFILE CLANG_MODULE_CACHE_PATH=/private/tmp/hindsight-release-cache ./scripts/qualify-release.sh --candidate
```

Operator report: `build/release-reports/20261023-004553-candidate/`. Both preflight
and gate exited zero. The report identifies base commit
`6ed93c74b1abb938a6f42adf3174726bc8863443` and a dirty working tree; it is not a
claim that the release was tested from a clean checkout. The tested product
sources were subsequently sealed into the release commit. Documentation and
gate-wiring updates followed qualification; no product sources changed afterward.

Evidence includes:

- 371 worker tests; 16 deterministic reconstruction artifact fixtures.
- Recovered-source matrix: 544 configurations, 100,640 native comparisons.
- Void/call/Boolean matrix: 92 configurations, 4,176 native comparisons.
- SDK pointee matrix: 648 configurations, 59,400 native comparisons.
- Header matrix: 40 configurations, 152 successful syntax checks, eight expected
  language rejections.
- Actual Objective-C headers and scalar method adapters at `-O0`/`-O2`, Swift
  decoder/batch/Dump All checks, CLI byte equality, six runtime inputs per level
  and failing no-adapter controls.
- App/XPC integration, exact per-format and Dump All hashes, explicit failed
  outcomes, cancellation/resume, checkpoint tamper rejection and CLI SIGKILL
  recovery checks.
- Debug/Release builds, ARM64-only release executables, nested ad-hoc signatures
  and embedded-worker self-tests.

The three focused reconstruction matrices were executed separately against
`build/rust/debug/reworker` and then added to `scripts/test-macos.sh` so future
candidate runs retain them. Their commands are `test-recovered-void.py`,
`test-recovered-pointees.py` and `test-recovered-headers.py` under `scripts/`.

After ZIP creation, the extracted app's nested signatures, version/build and
architecture were checked again. Asset SHA-256 checksums establish file identity,
not publisher trust or absence of vulnerabilities.

Developer ID signing, notarization and credentialed release validation are
intentionally skipped until further notice. Manual UI, real-target,
memory-pressure and deployment matrices remain open. This research prerelease
does not complete the roadmap or establish general source/behavioral equivalence.
