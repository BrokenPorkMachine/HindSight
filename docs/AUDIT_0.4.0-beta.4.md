# HindSight 0.4.0-beta.4 Completeness and Correctness Audit

This audit reviewed the beta.3 tree across the application, CoordinatorService, native C bridge/shims, Rust worker and VectorEmu integration, project/case persistence, plugin execution, Xcode generation, release qualification, and documentation. Confirmed defects were fixed in beta.4 rather than merely recorded.

## Closed findings

### Compile and target completeness

- The generated Xcode topology is deterministic and regenerated byte-identically.
- The application type-check gate covers every `App/*.swift` and app-target `Shared/*.swift` source.
- A new CoordinatorService gate type-checks the complete service Swift target together against `HindSightBridge.h`, closing the gap left by isolated host checks.
- The beta bundle test now uses the actual generated product name, `CoordinatorService.xpc`, and verifies the service executable, `reworker`, and `vg-emu-server` individually.

### Failure safety and concurrency

- Shipping Swift no longer contains force unwraps, forced casts, `try!`, `fatalError`, `preconditionFailure`, or `assertionFailure` in production source.
- Firmware/runtime network callbacks use a locked synchronous-result container instead of implicitly-unwrapped callback state.
- VectorEmu/iPhemeral output and scripting-process output use lock-protected bounded buffers.
- Firmware helper tools continuously drain stdout/stderr while running, avoiding pipe-buffer deadlocks on large `unzip -Z1` output.
- Timed-out helper/plugin processes terminate, escalate to `SIGKILL` if necessary, and do not read `terminationStatus` before termination is known.

### Persistence and filesystem boundaries

- Project roots and existing `project.sqlite` files must be real, non-symlink filesystem objects.
- New project roots are created private (`0700`).
- Captured binaries are removed again if database publication fails, so the project store does not knowingly leave orphan objects after a failed transaction.
- Investigation Ledger storage rejects symlinked project roots, `.vectorglass` directories, ledgers, and backups. A regression test covers symlink redirection outside the project.
- Plugin installation/execution rejects symlinked package components and bounds package entry count and total bytes.

### Network and external-process correctness

- Catalog/download URL construction is fallible rather than force-unwrapped.
- Downloads require the final response to remain HTTPS and return a 2xx status.
- Firmware helper output is bounded while streaming, not only after process exit.

### Release engineering

- Rust/VectorEmu remains pinned to the declared Rust 1.90 MSRV and Cargo lockfiles are structurally checked.
- Capability schema and bridge payload remain exact-parity generated contracts.
- Notarization now requires an explicit Developer ID Application signing identity and development team; the Release app is built with hardened runtime, submitted, stapled, and staple-validated.
- Python scripts intended for direct invocation have executable permissions.
- The validator rejects the SDK/API regressions seen during beta bring-up, including one-parameter SwiftUI `onChange`, invalid mixed `frame(width:minHeight:)`, production Swift crash primitives, and forced unwraps.

## Validation performed in this environment

- 86 Python/native tests passed; 6 optional LLVM-oracle tests skipped because the oracle is unavailable.
- All Foundation-only Swift contracts passed, including target, disassembly, graph, binary workspace/diff, runtime correlation, trace, evidence graph, and ledger/recovery contracts.
- Every shipping Swift source parses successfully with the available Swift compiler.
- The portable Apple-Silicon Hypervisor API shim compile test passes.
- Capability schema/bridge parity, Cargo lockfile structure, Rust 1.90 MSRV source checks, shell syntax, and deterministic Xcode project generation pass.

## Remaining beta qualification risks

These are not hidden source TODOs; they require the actual Apple Silicon release environment or physical targets and therefore remain beta/RC exit work:

1. Full Xcode Debug and Release compile/link with the macOS SDK.
2. Full Rust builds/tests for the main worker and VectorEmu with the pinned Rust 1.90 toolchain.
3. Real authorized native-debugger attach/launch/step/breakpoint/memory/module/backtrace matrix.
4. VectorEmu and Hypervisor hardware smoke tests against authorized research images/guests.
5. 8 GiB memory-pressure and long-session tests, including analysis, graph, binary diff, runtime trace, and case persistence.
6. Developer-ID Release signing plus successful Apple notarization/stapling on the release host.
7. Beta-user regression testing on diverse real Mach-O inputs and corrupted/malformed fixtures beyond the automated corpus.

Until those host/target gates pass without P0/P1 defects, the correct channel remains **beta**, not RC.
